# 企业 HR 数字员工 — 智能体项目

## 项目简介

本项目是一个基于 AI 的企业 HR 数字员工系统，采用「豆包风格」AI 原生对话式工作台设计。用户通过自然语言对话即可完成招聘咨询、简历解析、考勤查询、薪酬答疑、入离职办理等全部 HR 业务操作。

## 技术架构（三层结构）

```
┌─────────────────────────────────────────────────┐
│  前端层（Gradio 4.x+）                           │
│  豆包风格对话式工作台 · CSS自定义 · 单文件app.py  │
├─────────────────────────────────────────────────┤
│  智能体层（LangChain）                           │
│  意图识别 → 工具路由 → RAG检索 → 流式回复        │
├─────────────────────────────────────────────────┤
│  数据服务层                                      │
│  · SQLite 关系数据库（员工/考勤/薪酬/招聘）       │
│  · Chroma 向量库（员工手册/考勤制度/个税规则）    │
└─────────────────────────────────────────────────┘
```

## 快速启动

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置环境变量（已预置，按需修改 .env）
#    主要配置项：DEEPSEEK_API_KEY / DATABASE_PATH

# 3. 启动应用
python app.py

# 4. 浏览器访问
#    http://127.0.0.1:7860
```

## 前端设计规范（豆包风格）

### 视觉体系
| 元素 | 色值 | 说明 |
|------|------|------|
| 主色调 | #165DFF | 按钮、用户气泡、激活态 |
| 页面背景 | #ffffff | 主区纯白 |
| 侧边栏背景 | #f7f8fa | 浅灰 |
| 用户气泡 | 渐变 #165DFF→#4080FF | 蓝色渐变 |
| AI气泡 | #f7f8fa | 浅灰 |
| 一级文字 | #1d2129 | 正文 |
| 二级文字 | #4e5969 | 次要信息 |
| 分割线 | #eceef1 | 极淡 |

### 布局规范
- **左侧边栏**：固定260px，新建对话+会话列表+HR工具箱+用户栏
- **右侧主区**：自适应宽度，48px顶栏+聊天区+底部输入卡片
- **圆角**：大气泡/输入框16px，按钮/卡片10px，标签6px
- **间距**：8px为基础单位

### 交互特性
- 对话优先：所有HR业务通过自然语言完成
- 流式输出：打字机效果逐字显示
- 悬浮看板：侧边数据看板，不跳转页面
- 快捷提示：欢迎页4个功能卡片+4个快捷问题标签
- Enter发送 / Shift+Enter换行
