# 考勤管理制度

## 一、打卡规则
1. 上班打卡时间 09:00 前，下班打卡时间 18:00 后；午休 12:00-13:00 不计入工时。
2. 晚于 09:10 打卡记录为「迟到」；早于 17:50 打卡离岗记录为「早退」。
3. 当日既无上班也无下班打卡且未提交请假，记录为「缺勤」。
4. 已提交有效请假（状态为已批准）的日期，考勤状态记为「请假」。

## 二、加班管理
1. 加班须事前在系统提交《加班申请》并经直属主管审批。
2. 审批通过的加班计入 `overtime_hours`，可用于后期调休（调休类型）。
3. 未经审批的滞留不认定为加班。

## 三、异常处理
1. 忘打卡：应于当日或次日补交《补卡申请》，经主管确认后更正记录。
2. 连续缺勤 3 日且无请假视为严重违纪，按公司制度处理。

## 四、考勤与薪酬关联
1. 迟到/早退按月度累计，超出容忍次数部分扣减绩效。
2. 缺勤按事假标准扣薪，并影响全勤奖评定。
